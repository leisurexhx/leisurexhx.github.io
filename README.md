## 研究项目

| 方向 | 研究问题 | 主要方法 |
|---|---|---|
| QF方向 · 2026.06–至今 | 相同年度因子清单，不同预处理为何改变预测和组合？ | 冻结因子与训练协议、信息限制与数值编码对照 |
| EJOR方向 · 2026.07–至今 | 上游给定选股名单后，相同预测为何产生不同账户结果？ | 冻结输入/敞口、部分调整、支持集合与交易实施 |
| KAIS方向 · 2026.08–至今 | 减少资本占用与择时如何分开？ | 冻结篮子、P联合否决/Joint确认参与、资本匹配及共变 |

以上是研究手稿方向，不代表期刊录用或发表。模型标签层、代理账户、历史开发与其它窗口分开；无实盘收益声明。

## 可运行的合成机制示例

```bash
python demo/partial_adjustment_demo.py --half-life 5 --names 100
python -m unittest discover -s demo -p 'test_*.py' -v
```

这是本次新编写的教学示例，不是机构源代码。100只旧股与100只新股互不重合；先混合再Top-N截断，可以使名义部分调整变成旧成员保留。真实风险投影、交易阻碍、价格变化等均未纳入，不能当作收益回测。
